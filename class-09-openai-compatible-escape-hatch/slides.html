The OpenAI-compatible
escape hatch

Cambia dónde corre la inteligencia sin reescribir el cliente.

Pregunta esencial

¿Qué conserva una API compatible y qué debes volver a verificar?

Compatibilidad de forma no significa identidad de capacidades.

Frontera
cliente OpenAI SDK → HTTP /v1 → servidor QVAC → modelo local

http://localhost:11434/v1/ es el endpoint local por defecto.

Contrato mínimo
GET /v1/models POST /v1/chat/completions stream:true → SSE → [DONE]

Descubre el modelo real; no asumas que el nombre cloud existe localmente.

SSE

Streaming es transporte, no persistencia.

Acumula delta.content, maneja [DONE] y confirma el turno solo si la terminación es válida.

Configuración

QVAC_BASE_URL y QVAC_API_KEY deben ser inyectables. Nunca conviertas una clave cloud en fallback automático de datos privados.

Se conserva / se verifica

Conserva

messages · streaming · timeout · cancelación

Verifica

modelo · tools · JSON · visión · contexto · calidad

Tres dependencias
  1. ¿Necesito red? localhost no requiere Internet.
  2. ¿Necesito servidor? Sí, el cliente no ejecuta el modelo.
  3. ¿Necesito assets? Modelo y tokenizer deben estar provisionados.
Break it

Detén servidor · usa modelo incorrecto · rompe /v1.

Clasifica ECONNREFUSED, 404, 400 y timeout: infraestructura, ruta, capability o carga.

Measure it

Compara local/cloud con TTFT, duración, tok/s, tamaño, modelo y hardware. La media sin contexto no es evidencia.

Fail closed

Localhost no equivale automáticamente a modo avión.

Para datos privados, un servidor caído debe bloquear y explicar; el fallback remoto requiere decisión explícita.

Definition of done
  • ☐ /models y completion probados
  • ☐ SSE y errores clasificados
  • ☐ Adapter con base URL/modelo/capabilities
  • ☐ ADR y mediciones guardados
Takeaway

Una frontera estable reduce el costo del cambio.

Puente: decide qué cruza fronteras de datos y confianza → Clase 10.
