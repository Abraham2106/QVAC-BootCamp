Pregunta esencial

¿Qué conserva una API compatible y qué debes volver a verificar?

Compatibilidad de forma no significa identidad de capacidades.

Frontera estable
cliente OpenAI SDK → HTTP /v1 → servidor QVAC → modelo local

baseURL se convierte en una decisión de colocación.

Contrato mínimo
  1. GET /v1/models descubre IDs reales.
  2. POST /v1/chat/completions prueba completion normal.
  3. stream: true prueba SSE y [DONE].
SSE

Streaming es transporte, no persistencia.

Acumula delta.content, maneja [DONE] y confirma el turno solo cuando la terminación es válida.

Adapter

Conserva

messages · streaming · timeout · cancelación

Normaliza

base URL · model ID · errores · capabilities

No asumas equivalencia

Modelo, tools, JSON, visión y contexto necesitan pruebas propias.

El nombre del endpoint no garantiza la misma calidad ni las mismas opciones.

Tres dependencias
¿red? localhost no requiere Internet
¿servidor? el cliente no ejecuta el modelo
¿asset? modelo + tokenizer deben existir
Predict → Run

Detén el servidor. ¿Qué debe ocurrir?

Predice ECONNREFUSED, sin fuga de datos y sin fallback remoto silencioso.

Errores que enseñan

404

ruta o versión incorrecta

400

cuerpo o capability no soportada

408/504

timeout de carga o generación

Demo beats
  1. Lista modelos locales.
  2. Ejecuta normal y SSE.
  3. Prueba un parámetro incompatible.
  4. Repite con red bloqueada.
Measure it

TTFT · duración total · tokens observados · status HTTP · bytes fuera de localhost.

Compara rutas con el mismo prompt, modelo y hardware cuando sea posible.

Fail closed

Para datos privados, un catch no es una política.

Fallback remoto requiere endpoint permitido, consentimiento, timeout acotado y ausencia de datos prohibidos.

Definition of done
  • ☐ /models, normal y SSE probados
  • ☐ Errores clasificados por causa
  • ☐ Matriz de capabilities verificada
  • ☐ ADR y mediciones guardados
Takeaway

Una frontera estable reduce el costo del cambio.
