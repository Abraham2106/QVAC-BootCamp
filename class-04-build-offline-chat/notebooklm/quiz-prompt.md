# NotebookLM Quiz — Clase 4

> Pega este prompt en NotebookLM con SOLO las fuentes enfocadas de esta clase.

---

Genera un quiz difícil de **10 preguntas** para:

**Clase 4 — Build the Offline Chat**

Distribución:

- 2 conceptual explanation
- 2 prediction
- 2 metric interpretation (incluye TTFT vs tok/s)
- 2 diagnosis (stopReason, constraints, cache)
- 1 comparison
- 1 experimental-design problem

Requisitos:

- Al menos un escenario TTFT vs tokens/sec
- Al menos uno KV cache
- Al menos uno stopReason
- Al menos uno controlled variable design
- No trivia de nombres de API — exige razonamiento

Respuestas difíciles: párrafo corto con mecanismo causal.

Idioma: español, términos técnicos en inglés.
No inventes comportamiento QVAC fuera de fuentes.
