# NotebookLM — Flashcards Prompt

Genera flashcards difíciles para **Clase 06 — Local RAG and Private Knowledge**.

Distribución:
- 15% fundamentos;
- 25% causa/efecto;
- 20% prediction;
- 20% debugging;
- 10% measurement;
- 10% architecture decisions.

Prefiere:
- ¿Por qué retrieval debe inspeccionarse antes de generation?
- ¿Cómo sabes si falló retrieval o grounding?
- ¿Qué tradeoff introduce chunk size?
- ¿Qué NO prueba un score alto?
- ¿Por qué no debes inventar un threshold universal?
- ¿Qué debe hacer un sistema ante evidencia insuficiente?
- ¿De dónde debe venir provenance?

Respuestas de 2–5 frases y detalles QVAC solo desde las fuentes seleccionadas.
