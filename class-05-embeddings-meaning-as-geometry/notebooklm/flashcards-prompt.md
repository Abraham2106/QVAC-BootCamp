# NotebookLM — Flashcards Prompt

Genera flashcards difíciles para **Clase 05 — Embeddings: Meaning as Geometry**.

- 20% fundamentos;
- 25% causa/efecto;
- 20% comparación;
- 15% predicción;
- 15% debugging;
- 5% bridge to RAG.

Prefiere preguntas como:
- ¿Por qué un embedding no es una respuesta?
- ¿Qué NO prueba un score alto?
- ¿Por qué no debes comparar vectores de modelos distintos sin evidencia de compatibilidad?
- ¿Qué partes del semantic search son lógica de aplicación en el lab?
- ¿Cómo distinguirías query ambigua de corpus insuficiente?
- ¿Qué medirías si retrieval “se siente lento”?

Respuestas de 2–5 frases, usando solo las fuentes de la clase para detalles QVAC.
