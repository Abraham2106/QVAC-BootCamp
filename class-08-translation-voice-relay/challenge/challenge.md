# Challenge — Relay bilingüe resistente

Implementa español ↔ inglés con cinco segmentos, finales traducibles, IDs monotónicos, resultados fuera de orden, cola TTS máxima de dos, degradación a transcript y métricas. Entrega código, decision-record.md, metrics.csv y demo de 90 segundos en modo avión. Explica qué ocurre si la red se habilita después: el relay no debe cambiar de ruta silenciosamente.
