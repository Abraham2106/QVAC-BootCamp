Speech systems:
bytes → meaning → voice

ASR y TTS locales confiables empiezan con un contrato de audio.

Pregunta esencial

¿Cómo conviertes audio continuo en una conversación local medible?

La tubería tiene cuatro fronteras: captura, reconocimiento, síntesis y reproducción.

Modelo mental
micrófono / archivo → PCM normalizado → ASR → texto → TTS → PCM / WAV

Cada flecha es un contrato, no un callback improvisado.

Contrato de entrada

Declara

sampleRate · channels · sampleFormat · endianness · durationMs

Valida

WAV puede contener PCM; MP3/Opus requieren decodificación.

ASR
frames → features → tokens → segmentos

Whisper y Parakeet son opciones distintas: compara idioma, ruido, memoria, licencia y latencia.

Partial vs final

Lo provisional no es durable.

Los parciales sirven para feedback. Solo un segmento final debe entrar al historial o activar TTS definitivo.

Ventanas y VAD

Solapamiento

Cuida fronteras entre palabras, pero repite trabajo.

VAD

Ahorra inferencia en silencio, pero un umbral agresivo puede cortar consonantes.

TTS

Texto no es audio.

Verifica formato, sample rate y bytes de salida antes de reproducir. Primer audio y síntesis completa son métricas diferentes.

Correlación
turnId → audioFrame → transcriptFinal → speechChunk → turnDone

El mismo ID permite ordenar, cancelar y diagnosticar un turno.

Predict → Run → Explain

Envía 16 kHz a un backend de 48 kHz.

Predice: rechazo explícito, WER degradado o audio acelerado/lento. Ejecuta una sola variación y clasifica.

Demo beats
  1. Valida un archivo conocido.
  2. Ejecuta ASR y muestra segmentos.
  3. Envía solo el final a TTS.
  4. Repite con micrófono y red bloqueada.
Backpressure

La captura nunca espera a TTS.

Limita buffers, define cancelación y decide si descartar parciales o degradar a texto cuando el consumidor no alcanza.

Measure it

asrFirstTextMs · asrFinalMs · ttsFirstAudioMs · ttsTotalMs · bytes · razón terminal.

Reporta modelo, hardware, cuantización, ventana y sample rate.

Break it

Rompe una frontera, no todo el sistema.

  • Endianess invertido
  • Consumer lento
  • Cancelación durante TTS
  • Formato de salida inesperado
Definition of done
  • ☐ Tres entradas reproducibles
  • ☐ Parcial, final, error y cancelación distinguibles
  • ☐ Primer texto separado de primer audio
  • ☐ Diagnóstico por etapa y prueba offline
Takeaway

Una voz confiable empieza por contratos medibles.

Puente: encadena ASR → traducción → TTS sin bloquear captura en la Clase 08.
