QVAC · Módulo 3 · Clase 07

Speech systems

ASR + TTS sin perder el contrato de audio.

Pregunta esencial

¿Cómo conviertes audio continuo en una conversación local medible?

Bytes, texto y voz son fronteras distintas.

Contrato
micrófono / archivo → PCM normalizado → ASR → texto → TTS → PCM/WAV

Declara sampleRate, channels, sampleFormat, endianness y duración.

No mezcles conceptos

PCM

Muestras, no un contenedor.

WAV / MP3

Contenedor o códec; pueden requerir decodificación.

ASR
frames → features → tokens → segmentos

Whisper o Parakeet se eligen por idioma, ruido, memoria, latencia y hardware.

Streaming

Ventana, solapamiento y VAD son políticas.

El solapamiento cuida fronteras pero duplica trabajo; VAD ahorra inferencia pero puede cortar consonantes.

TTS

Texto no es audio.

Verifica el formato de salida y no asumas que su sample rate coincide con el micrófono.

Voice relay
turnId → audioFrame → transcriptFinal → speechChunk → turnDone

El mismo ID permite ordenar, cancelar y diagnosticar un turno.

Predict → Run

Envía 16 kHz a un backend configurado para 48 kHz.

Predice: fallo explícito, audio acelerado/lento o degradación de reconocimiento. Luego mide.

Measure it

Captura · ASR first-text · ASR final · TTS first-audio · TTS total · bytes · razón terminal. Reporta modelo, hardware y cuantización.

Definition of done
  • ☐ PCM validado antes de ASR
  • ☐ Segmentos con timestamps e ID
  • ☐ Backpressure y cancelación observables
  • ☐ Red bloqueada con evidencia de localidad
Takeaway

Una voz confiable empieza por contratos medibles.

Puente: encadena ASR → traducción → TTS sin bloquear captura en Clase 08.
